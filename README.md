## The entry

One original one-line office joke, written by `main.py` to `/output/entry.txt`:

> IT fixed the printer by unplugging it and plugging it back in, which is also how HR handled my last three complaints.

117 characters, one line — inside the 1–200 character gate.

## How it works

`main.py` validates the joke (non-empty, single line, at most 200 characters),
then writes it to `/output/entry.txt`. It creates the output directory if
needed and never deletes it, since the grader mounts it.

Run it with:

```sh
python3 main.py
```
